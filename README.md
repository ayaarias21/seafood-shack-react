# 🦀 The Seafood Shack — React App

A full-featured restaurant website rebuilt in React + Tailwind CSS (Homework 3).

## Features
- **Home** — Hero section, signature dishes, CTA
- **Menu** — Full ordering system with cart (persisted in localStorage)
- **Digital Menu** — Interactive flip cards for each dish
- **About** — Story and stats
- **Gallery** — Lightbox with keyboard-style navigation
- **Contact** — Message form with confirmation
- **Reservation** — Full booking form with confirmation
- **Checkout** — Cart summary, order type selector (pickup/delivery/card)

## Tech Stack
- React 18 + Vite
- React Router DOM (client-side routing)
- Tailwind CSS v3
- Context API for global cart state
- Google Fonts (Playfair Display, Poppins, Dancing Script)

## Getting Started

```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deployment
Deploy the `dist/` folder to any static host (Netlify, Vercel, GitHub Pages).
